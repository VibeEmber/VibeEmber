## 我们想解决什么

Vibe Coding 降低了把产品做出来的门槛，却没有降低把它交给真实用户的门槛。

很多开发者会遇到这些情况：

- 产品已经上线，但没有人知道
- 缺少首批用户，无法判断真实需求
- 自己用着没问题，别人一用就卡住
- 需要少量真实用户完成早期测试
- 烧了很多 Token 做出产品，却没有验证它能不能走下去
- 不知道别人是否已经做过类似的事
- 没有团队，也没有稳定的开发者圈子

VibeEmber 把分散的独立开发者聚在一起：每个人既可以展示作品，也可以成为别人的第一批用户。微光汇成星火，星火才可能燎原。

## 谁适合加入

- 用 AI 和 Vibe Coding 做产品的开发者
- 正在运营小程序、Web 应用、App 或浏览器插件的个人
- 需要真实体验反馈的早期产品团队
- 想找项目灵感、合作伙伴或细分赛道的人
- 愿意先认真体验别人的产品，再获得社区帮助的人

不会写代码也可以加入。只要你愿意认真体验、给出有效反馈，就是社区有价值的成员。

## 社区怎么玩

```text
用 GitHub 或邮箱验证码登录
        ↓
发布可体验的真实产品（截图必传，写清需要的帮助）
        ↓
通过社区审核并公开展示
        ↓
先帮别人完成体验任务，赚取火苗
        ↓
用火苗发起助燃：选反馈类型、写清单、冻结赏金
        ↓
获得有效反馈后改进产品，把火烧旺
```

### 1. 登录 / 注册

使用 **GitHub** 或 **邮箱验证码（OTP）** 登录，新邮箱会自动注册。之后发布的产品、审核状态和互助记录都记在这个账号上。

### 2. 发布产品

填写产品名称、一句话介绍、访问入口、产品类型，以及现在最需要的帮助（至少 20 字）；至少上传 1 张产品截图，可选上传 Logo。提交后系统会为产品链接生成二维码。

好的投稿不必写成商业计划书，讲清三件事即可：

1. 这是什么产品？
2. 它为谁解决什么问题？
3. 你现在需要什么样的真实帮助？

### 3. 等待审核

新项目默认进入审核队列。管理员会确认链接能否访问、介绍是否真实，以及是否符合社区公约。

- **审核中**：已提交，尚未公开
- **已上线**：已通过审核，出现在社区首页
- **已驳回**：需要修改，投稿者可查看原因

### 4. 帮助别人

浏览助燃厅里的任务，看清反馈类型和说明后再领取。体验之后按三问作答，并上传一张使用截图。照抄介绍或重复粘贴过不了核验。

### 5. 发起互助

有火苗也不一定能发。产品必须已上线、有可体验入口、有截图，任务要写清说明并选定反馈类型（首次使用 / 找问题 / 新手引导 / 文案体验 / 带来用户）。发起时按「赏金 × 名额」冻结火苗。

## 火苗是什么

火苗是社区里记录贡献的互助积分，规则公开、定额发放，不按「写得好不好」打分。

```text
注册赠送 20 火苗
完成真实体验报告（三问 + 截图，验收通过） → 获得任务赏金
成功带来用户（对应任务类型 + 证据）     → 获得该任务赏金
让自己的产品燎原                       → 消耗已冻结的火苗
```

点赞、收藏、短评、只打开链接、复读产品介绍、互刷小号，都不给火苗。发起人按清单验收；48 小时不处理会自动通过。管理员抽查已通过样本，不实反馈会追回火苗。个人中心可查看完整账本。

## 社区公约

### 我们鼓励

- 发布自己真正参与制作的产品
- 清楚说明产品现阶段的问题和需求
- 给出可执行、有上下文的体验反馈
- 尊重每一个还很粗糙的早期产品
- 对产品、数据、合作关系和收益保持诚实

### 我们拒绝

- 恶意软件、诈骗、钓鱼和违法内容
- 没有真实体验的批量点击与注册
- 刷广告、刷好评、刷排名和其他虚假数据
- 诱导或强迫参与者提供好评
- 抄袭他人产品、素材、介绍或投稿
- 泄露体验过程中接触到的隐私和测试数据

## 本地快速启动

需要 Node 24 LTS、pnpm 9、Docker。版本见仓库根目录 [`.nvmrc`](.nvmrc)。

```bash
pnpm install
docker compose up -d          # PostgreSQL :5432 / MinIO :9000 / Mailpit :8025
pnpm db:migrate               # 应用 Prisma 迁移
pnpm db:seed                  # 写入精选项目
pnpm dev                      # web :3000 / api :4000 / worker
```

开发环境的验证码邮件在 [http://localhost:8025](http://localhost:8025)（Mailpit）查看。GitHub 登录需要在 `.env` 中填写 OAuth App 的 Client ID / Secret，回调地址为 `http://localhost:4000/api/auth/callback/github`。

完整架构、端口、环境变量与生产部署见 **[开发文档](docs/DEVELOPMENT.md)**。
